# どろぼう猫とおさかな美術館 3D

モナカ・おはぎ・大福から主人公を選んで、立体の美術館に忍び込む3Dブラウザーゲームです。全3ステージ、おさかな18個。Three.js r170を同梱しているため、インストールやビルドは不要です。WebGL 2対応ブラウザーが必要です。

## 3匹の猫

選択欄は左からモナカ（キジ白）、おはぎ（鼻元の黒い模様がある白黒）、大福（ふわふわの白とシルバー）。写真をもとに生成したアニメ風イラストを選択画面に使用し、その特徴を3Dメッシュでも再現しました。歩行・しっぽ・向きがアニメーションします。写真に見えていない背中や後ろの模様は、見えている特徴から補っています。

冒険中でも切り替え可能。選択は端末のブラウザーに保存され、階を進んでも再挑戦しても保持されます。性能は3匹とも同じです。

「前・横・後ろを3Dで見る」から鑑賞ルームを開けます。前・横・後ろのボタンで方向を切り替え、ドラッグで自由に回転。「回す」で自動回転。ホイールで拡大できます。鑑賞中はゲームが止まり、戻ると同じ場所から再開します。

イラスト：`dist/assets/cat-trio-anime.png`。生成方法とプロンプトは `ARTWORK.md` に記載。

## 遊び方

画面内の左右のコントローラーは、スマートフォン・タブレットの指とPCのマウスで使えます。

- **左の丸「移動」**：倒した方向へ移動。少し倒すとゆっくり、大きく倒すと速く歩きます。
- **右の丸「視点」**：左右で見回し、上下でカメラの高さを調整します。
- 両方を同時に操作できます。指やマウスを離すと、その側だけ止まります。
- 中央の「かくれる」「毛糸玉」でアクション。PCは従来のキーボード操作も使えます。

完成版ZIPのいちばん上にある `index.html` をブラウザーで開くと、サーバーの起動なしで遊べます。画像・スタイル・ゲームコードをすべて内蔵したファイルです。

ソース版をローカルサーバーで動かす場合：

`npm start` を実行して http://localhost:4185 を開きます。

インストールなしで渡せる単体HTML版は、`node build-offline.mjs` で親フォルダーの `index.html` に出力できます。3Dライブラリと猫のイラストを1ファイルに内蔵し、外部画像やモジュールの読み込みを不要にしています。

- WASD / 矢印：移動
- SPACE：段ボール箱の近くで隠れる／箱から出る
- F：毛糸玉で警備員の気をそらす（8秒で再使用）
- ESC：一時停止
- V：猫のそばのカメラ／美術館の全体視点
- Q / E：カメラを45度ずつ回す
- 画面をドラッグ：カメラを回す
- ホイール：拡大・縮小
- スマホ・タブレット：左スティックで移動、右スティックで視点、中央ボタンでアクション

画面上部とゲーム画面の「？ 遊び方」で、手順と音の出し方を確認できます。遊び方を開いている間はゲームが止まり、閉じると再開します。

スマートフォン向けに左右独立のスティック、大きなアクションボタン、縦横の画面配置、開始時のゲーム画面への移動、3D描画負荷の軽減を入れています。画面サイズの確認とPCのマウス操作、自動チェックを行っており、スマートフォン・タブレット実機の性能や音声出力は未検証です。

`127.0.0.1` と `localhost` は開いている端末自身を指します。このPCの起動リンクをそのままスマートフォンで開くことはできません。スマートフォンへ届けるオンラインURLは、別途公開が必要です。

おさかなは近づくと自動で拾います。すべて集めたら左下の緑色の出口へ。警戒メーターが満タンになるとチャンスが1回減り、入口へ戻ります。拾ったお宝は保持されます。チャンスは3階を通して3回。時間制限はありません。

効果音は右上で切り替えられます。ゲーム進行はページの再読み込みでリセットされます。

初期状態の「♪ OFF」を押すとONになります。おさかなの取得、毛糸玉、発見、クリアで異なる短い電子音が鳴ります。音の設定はブラウザーに保存されます。

## 検証
