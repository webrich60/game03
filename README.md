# ねこねこ！ねずみハント 🐭

最中（モナカ）・おはぎ・大福・カステラから選んだ猫で、たくさんのネズミを捕まえる3Dアクションです。

## スマホ縦画面と鳴き声の修正（v2.5）

プレイ中は、実際に見えるブラウザー領域の幅と高さにゲームを固定します。アドレスバーの伸縮や拡大時の表示領域にも追従。コントローラーは3D映像と分けた下段に置き、端や下にはみ出さない構成です。ノッチ・ホームバーの余白も確保します。

縦画面では最初に公園全体を映します。「猫のそば」で近くへ、「公園全体」で広場全体へ切り替えられます。左上には全体地図を常時表示し、タップで拡大できます。オレンジの矢印が猫、灰色の点がネズミ、黄色の点・四角が金のネズミやボーナスです。

音はゲーム上端のスピーカーでもON/OFFできます。「にゃあ」はボタンやFキーを押した処理の中で音声を有効にし、再生準備ができてから鳴らします。以前の2つの電子音を、倍音・母音の響き・息を合成した約0.82秒の「にゃーん」に変更。実際の猫の録音ではありません。素材の取得や外部通信は不要です。試聴用は qa/nyaan-preview.wav。

一時停止画面から4匹を交代できます。交代では得点・時間・捕獲数を維持します。「メニューへ（プレイを終了）」で選択画面に戻れます。

### 猫の違いを見るタイミング

- 最中：弾む走り。捕獲とにゃあで前足を上げてジャンプ。走りは少し速く、とびつきは長め。
- おはぎ：きびきび行進。捕獲とにゃあで敬礼しておじぎ。移動中も近くのねずみを狙ってとびつく。
- 大福：左右にゆらゆら。捕獲とにゃあで前足ばたばた。3回目のとびつき着地で1回転。ボーナスを広めに拾う。
- カステラ：捕獲とにゃあで横に跳ね、スカーフを持ち上げてカプッ。にゃあの範囲と減速時間が少し大きい。

公園全体では小さな仕草が見えにくいため「猫のそば」に切り替えて確認してください。メニューの「前・横・後ろを3Dで見る」→「性格のしぐさ」では大きく見られます。

GitHub Pagesを更新する場合は、今回のZIP内の index.html に差し替えます。この作業では公開ページへのアップロードはしていません。

## ステージごとに変わる5つの公園（v2.4）

ステージをクリアして「次のステージへ」を押すと、地面の道・障害物・周囲の建物や木・空の色・照明がまとめて切り替わります。

| ステージ | 景色 |
| --- | --- |
| 1 のんびり広場 | 草原の十字路、池と橋、木のベンチと木箱 |
| 2 お花畑 | 桜色の木、花のアーチ、丸い散歩道と花壇 |
| 3 チーズ公園 | チェック柄の床、大きなチーズ模様、チーズのブロックと回る風車 |
| 4 夕焼け広場 | 紅葉、夕日、曲がりくねった飛び石、丸太とキャンプ |
| 5 夜の運動会 | 月と星、ランタン、走路ライン、観客席と表彰台 |

猫の選択欄の「5つの公園を見くらべる」で、順番に景色を確認できます。これはプレビューです。捕獲数・得点・時間を止めて、戻ると元のステージとカメラに復帰します。プレビュー内でステージが進むことはありません。

静的な風景は同じ形をまとめて描画し、切り替え時は前の風景のマテリアルとインスタンスのバッファを解放します。遊べる範囲と障害物の衝突範囲は引き継いでいます。景色はコードで作った3Dです。

## 右手で移動する操作（v2.3）

右下の大きい丸で移動。左上の小さい丸で視点を変え、左下の「とびつく」「にゃあ」を別の指で押せます。アクションは指を離す前、触れた瞬間に発動します。PCの矢印 / WASD・SPACE・Fも使えます。

プレイ中は中央の案内・得点ポップアップ・猫のセリフを表示しません。地図は左上に復活しています。捕獲数・得点・残り時間は上端、コンボ・効果アイコンは3D画面の外の下端で確認できます。ボタン下の短いゲージが戻ると再使用できます。

## 遊ぶ

**index.html** をブラウザーで開き、「ねずみを追いかける」を押します。猫を動かしてネズミに近づくだけで自動キャッチ！ 捕まえるための追加操作は必要ありません。

開発用は node server.mjs → http://127.0.0.1:4187/ 。このアドレスは起動したPC内だけの確認用です。オンライン公開は未実行です。

| 最中（モナカ） | やんちゃ | 前後の足をそろえた弾む走り。捕獲後は両前足を上げて2回ジャンプ。しっぽを大きく振る。少し速く、長めにとびつく。 |
| おはぎ | 真面目 | 背すじを伸ばして前足をきびきび振る行進。捕獲後は前足で敬礼しておじぎ。動きながらでも4.2m以内のねずみを狙ってとびつく。 |
| 大福 | おっちょこちょい | 左右にゆらゆら歩き、捕獲後は両前足をばたばた。とびつき3回ごとの着地で体が横に1回転。操作や得点は変わらず、ボーナスを1.6mの広さで拾える。 |
| カステラ | 優しい・おてんば、噛み癖あり | 横に跳ねて体をひねり、前足でラベンダーのスカーフを口元に持ち上げてカプッ。にゃあが5.6mまで届き、約2.8秒ゆっくりにする。 |

カステラは、猫自身の左耳の先が少し欠け、尻尾が通常の約半分です。前から見ると画面右の耳が欠けています。横ボタンではその耳が見える側を表示します。新イラストは3匹の絵柄に合わせて制作し、CASTELLA-ART.md に生成記録を保存しています。

性格紹介とセリフは猫の選択欄にあります。ゲーム中は文字の吹き出しを出さず、歩き方・前足・頭・しっぽ・体の動きで性格を表現します。

猫の交代で得点・捕獲数・残り時間はリセットされません。3Dルームの「性格のしぐさ」で、おじぎ・喜びのジャンプ・ころん・カプッを確認できます。

## 操作

| 操作 | タッチ・画面 | PC |
| --- | --- | --- |
| 移動 | 右の丸をドラッグ | 矢印 / WASD |
| 視点 | 左上の小さい丸をドラッグ | 画面ドラッグ |
| とびつく | ↟ とびつく | SPACE |
| ネズミを遅くする | にゃあ | F |
| 広場全体を見る | ◈ 全体 | V |
| 一時停止・再開 | Ⅱ / ▶ | Esc |

「とびつく」は短いダッシュとジャンプ。届く範囲も広がります。1.35〜1.5秒の再使用待ちがあります。止まっているときに押すと、近くのネズミへ向かいます。おはぎは移動中でも近くのネズミを狙います。「にゃあ」は5m以内のネズミを約2秒遅くし、再使用まで6秒です。

## ステージ

| ステージ | 捕獲目標 | 同時にいるネズミ | 逃げる基本速度 | 時間 |
| --- | --- | --- | --- | --- |
| 1 | 8匹 | 12匹 | 1.7 | 90秒 |
| 2 | 12匹 | 16匹 | 2.2 | 100秒 |
| 3 | 16匹 | 20匹 | 2.7 | 110秒 |
| 4 | 20匹 | 24匹 | 3.2 | 120秒 |
| 5 | 24匹 | 28匹 | 3.7 | 130秒 |

目標の匹数でクリアし、「次のステージへ」で進みます。得点はボーナスやハイスコアのための数字です。時間切れでも同じステージから再挑戦でき、前のステージの得点は残ります。

ネズミは猫から離れる方向へ逃げ、壁や箱をよけます。捕まえたネズミは別の場所に再出現するため、広場からいなくなりません。猫・ネズミ・箱・アイテムはThree.jsによる立体描画です。

## 得点とボーナス

- 普通のネズミ：10pt。金のネズミ：50pt。
- 7秒以内に続けて捕まえるとコンボ。2匹目2倍、3匹目3倍、最大5倍。
- チーズ：30pt。
- スター：100pt。
- 時計：残り時間+10秒（最大180秒）。
- スピード：猫が8秒間速くなる。
- スロー：すべてのネズミが5秒間ゆっくりになる。
- ×2：8秒間、捕獲と得点アイテムの点数が2倍。コンボにも重なります。
- クリアボーナス：残り秒数×2pt。

3匹捕まえるごと、または12秒ごとにボーナスが出現します。近づくだけで取れます。アイテムは一定時間で消えます。

右上で音を切り替えられます。効果音はプログラムで生成します。猫の選択・音設定・最高得点はブラウザー内に保存されます。ステージ途中の保存はありません。

## 対応と検証

スマホ・タブレット向けに縦横の配置、独立した右の移動・左の視点スティックと同時タッチ対応のボタン、描画解像度制限、影の軽量化、静的オブジェクトの描画集約があります。WebGL 2対応のブラウザーが必要です。スマホ実機の速度・音・触り心地は未確認です。

配布用index.htmlには画像、CSS、JavaScript、Three.jsを埋め込んでいます。追加ダウンロードや外部CDNは不要です。スマホのファイルプレビューがJavaScriptを実行しない場合はHTTP配信が必要です。
